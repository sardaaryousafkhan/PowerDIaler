**Why deferred:** No in-room strangers available during the instrumented capture session. Tunnel substitution would measure the tunnel, not the app — that is an explicit FAIL of test design.

## Protocol

1. Sit each stranger at the demo machine running `:4173`.
2. Task: "Sign in, open a campaign, and start a call."
3. Stopwatch from first click → live-call screen visible.
4. Ask:
   - a) "Did anything feel slow or laggy?"
   - b) "Was there any moment where you waited for the screen?"
   - c) "On a scale of 1–10, how fast did this feel to use?"

## Pass criteria

- All 3 say no to (a) and (b)
- All 3 rate (c) ≥ 8
- All 3 complete task in under 20 seconds total
