# Ops checklist (you, after a customer pays)

1. Confirm payment received (outside this system).
2. Open `https://derivedstudio.com/license/admin/`.
3. **Create license** — customer label, machine limit (default 2), optional expiry.
4. Copy the key once → email/SMS it to the customer.
5. Point them to download: `https://derivedstudio.com/dashdialer/`.
6. If they stop paying → **Revoke**.
7. If they get a new PC and hit the machine limit → **Clear devices** or raise the limit.

Never store Twilio or campaign data on Namecheap.
