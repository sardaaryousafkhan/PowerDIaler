How it works

  1. You pay Derived Studio (invoice, transfer, etc.).
  2. We create a license key in the admin panel and send it to you.
  3. Install DashDialer → open License → paste the key.
  4. If a subscription ends, we revoke the key; the app locks paid features on the next check.
